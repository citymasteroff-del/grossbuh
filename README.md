# Гроссбух — учёт доходов и расходов

Приложение для учёта доходов/расходов по банковским выпискам PDF и фото чеков/накладных.
Устанавливается на телефон как PWA (иконка на главном экране, работает офлайн),
с опциональной синхронизацией в Google Таблицу.

## Что внутри

```
index.html              — само приложение
manifest.json           — манифест PWA (иконка, имя, цвета)
sw.js                   — service worker (офлайн-кэш)
icons/                  — иконки приложения (192px, 512px)
google-apps-script/
  Code.gs               — код для Google Таблицы (синхронизация с паролем)
```

## Шаг 1. Залить на GitHub

1. Создай новый репозиторий на github.com (например `ledger-app`), можно приватный.
2. На странице репозитория нажми **Add file → Upload files**.
3. Перетащи туда содержимое этой папки **кроме** `google-apps-script/` (её трогать не нужно —
   это отдельный файл для вставки в Google Таблицу, на GitHub он не нужен, но не помешает, если тоже зальёшь).
4. Закоммить (Commit changes).

## Шаг 2. Включить GitHub Pages (чтобы работало как приложение)

1. В репозитории: **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: `main`, папка `/ (root)`.
3. Сохранить. Через 1-2 минуты появится ссылка вида:
   `https://<твой-логин>.github.io/ledger-app/`

⚠️ Важно: PWA (установка на телефон, офлайн-режим) работает только по **https** — GitHub Pages это как раз даёт бесплатно. Просто открыть `index.html` с телефона файлом — установка на главный экран работать не будет.

## Шаг 3. Установить на телефон

**Android (Chrome):** открой ссылку с Pages → меню (⋮) → **«Установить приложение»** / «Добавить на главный экран».

**iPhone (Safari):** открой ссылку → кнопка «Поделиться» → **«На экран «Домой»»**.

Появится иконка Гроссбуха как у обычного приложения, откроется на весь экран, будет работать без интернета (данные хранятся в браузере).

## Шаг 4. Настроить синхронизацию с Google Таблицей (по желанию)

1. Открой (или создай) Google Таблицу.
2. Меню **Расширения → Apps Script**.
3. Сотри код-заглушку, вставь целиком содержимое файла `google-apps-script/Code.gs`.
4. В строке `const PASSWORD = "МОЙ_СЕКРЕТНЫЙ_ПАРОЛЬ";` замени на свой пароль.
5. **Развернуть → Новое развёртывание**:
   - Тип: **Веб-приложение**
   - Выполнять как: **Я**
   - Доступ: **Все (Anyone)**
6. Скопируй выданный URL (заканчивается на `/exec`).
7. В приложении Гроссбух → вкладка **«Синхронизация»** → вставь URL и пароль → **«Сохранить настройки»**.
8. Кнопка **«⬆ Отправить в таблицу»** — выгружает текущие операции в таблицу (полная перезапись листа `Transactions`).
   Кнопка **«⬇ Загрузить из таблицы»** — подтягивает данные из таблицы в приложение (заменяет локальные).

Если после изменения кода в Apps Script синхронизация перестала работать — нужно сделать
**новое развёртывание** (Развернуть → Управление развёртываниями → редактировать → новая версия), просто сохранение кода недостаточно.

## Обновление приложения в будущем

Если попросишь что-то изменить в приложении — просто замени `index.html` (и другие изменённые файлы)
в репозитории на GitHub тем же способом (Add file → Upload files, с перезаписью). GitHub Pages подхватит
изменения автоматически за 1-2 минуты.
